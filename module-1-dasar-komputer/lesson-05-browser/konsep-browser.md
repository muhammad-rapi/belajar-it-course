## How Browser Works

**1. Parse HTML** → build DOM tree  
**2. Parse CSS** → build CSSOM  
**3. Combine** → Render tree  
**4. Layout** → calculate position  
**5. Paint** → render pixels  

**Browser components**:
- **Rendering engine**: Webkit (Safari), Blink (Chrome/Edge), Gecko (Firefox)
- **JavaScript engine**: V8 (Chrome), SpiderMonkey (Firefox)
- **Networking**: Handle HTTP requests
- **Storage**: LocalStorage, Cookies, IndexedDB

**Buka DevTools**: `F12` atau `Cmd+Option+I` (Mac) / `Ctrl+Shift+I` (Windows)
