## Summary

**Cara browser menampilkan halaman**
- HTML dibaca jadi DOM, CSS dipasang ke elemen, lalu hasilnya dihitung dan digambar ke layar.
- DOM adalah versi hidup di memori browser dan bisa diubah JavaScript.

**DevTools**
- Buka dengan `Cmd + Option + I` (Mac) atau `F12` (Windows / Linux), atau klik kanan lalu Inspect.
- Elements buat ngecek dan ngubah HTML serta CSS.
- Console buat baca error dan nyoba JavaScript.
- Network buat liat request, status code, dan response.

**Hal yang perlu diingat**
- Perubahan di DevTools nggak disimpan. Refresh, dan semuanya balik.
- Jangan nempel kode asing di Console.

**Kemampuan setelah lesson ini**
- Bisa ngecek elemen dan CSS yang kepakai di halaman mana pun
- Bisa baca pesan error di Console
- Bisa nyari request yang gagal atau lambat di Network
