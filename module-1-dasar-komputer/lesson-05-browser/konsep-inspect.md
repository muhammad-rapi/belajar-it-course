## Inspect Element

**Cara 1**: Klik kanan → "Inspect" / "Inspect Element"  
**Cara 2**: `Cmd+Option+C`, hover element, klik

**Yang bisa lu lakukan**:
- Liat HTML structure
- Edit HTML live (double-click)
- Edit CSS live (sidebar kanan)
- Delete element (select → Delete key)
- Check box model (margin, padding, border)

**Console tab**:
```javascript
console.log("Hello");
document.querySelector("h1").textContent = "Changed!";
```

**Network tab**:
- Liat semua request (HTML, CSS, JS, images, API)
- Check status code (200, 404, dll)
- Liat response data
- Check request headers

**Practice**: Buka google.com, inspect, edit tulisan "Google" jadi nama lu.
