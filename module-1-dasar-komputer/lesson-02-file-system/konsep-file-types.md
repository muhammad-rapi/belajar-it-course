# File Types & Extensions

## Text vs Binary Files

**Text files**: Human-readable (`.txt`, `.md`, `.html`, `.py`)  
**Binary files**: Machine-readable (`.jpg`, `.exe`, `.mp4`, `.docx`)

## Extensions

Extension (`.txt`, `.jpg`) itu hint tentang file type, tapi **bukan guarantee**.
