# File System & Path - Introduction

## Masalah yang Akan Kita Selesaikan

Kamu pernah download file, terus **ga ketemu file-nya dimana**? Atau **error "file not found"** padahal file-nya ada? Atau bingung bedanya `C:\Users\` vs `../folder/`?

Ini semua masalah **file system & path**. Kalau kamu ga ngerti gimana komputer organize files dan gimana cara refer ke file (path), coding kamu bakal sering ketemu error yang frustrating.

Lesson ini bakal jelasin **mental model** file system: gimana komputer simpen dan organize files, dan gimana cara kamu navigate/refer ke files dengan benar.

## Analogi: Alamat Rumah

> File system itu kayak sistem alamat di kota:
> - **Folder** = Blok/RT/RW/Kelurahan (group rumah)
> - **File** = Rumah individual
> - **Path** = Alamat lengkap ("Jl. Merdeka No. 10, RT 01/RW 02, Kelurahan X, Kota Y")
> - **Root directory** = Negara (top-level)
> 
> Kalau kamu mau kirim paket ke rumah seseorang, kamu butuh **alamat lengkap** (absolute path). Atau kalau kamu udah di kelurahan yang sama, cukup bilang "rumah no. 10 RT 01" (relative path).

File system works exactly like this.
