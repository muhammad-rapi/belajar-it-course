# Folder Hierarchy & Path

## Tree Structure

Files organized dalam **tree structure** (pohon):

```
C:\ (root)
├── Users/
│   ├── Rapi/
│   │   ├── Documents/
│   │   │   ├── project-1/
│   │   │   └── notes.txt
│   │   ├── Downloads/
│   │   └── Desktop/
│   └── Public/
├── Program Files/
└── Windows/
```

## Absolute vs Relative Path

**Absolute path**: Alamat lengkap dari root.
```
C:\Users\Rapi\Documents\notes.txt
/Users/Rapi/Documents/notes.txt
```

**Relative path**: Alamat dari posisi current directory.
```
../Documents/notes.txt
./project-1/file.txt
```
