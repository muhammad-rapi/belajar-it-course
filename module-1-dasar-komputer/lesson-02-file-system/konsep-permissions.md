# File Permissions

## Read, Write, Execute

Every file punya permissions:
- **Read (R)**: Bisa baca isi file
- **Write (W)**: Bisa edit/delete file
- **Execute (X)**: Bisa run file (kalau file = program/script)

## User vs System

**User files**: Kamu punya full control  
**System files**: Protected (butuh admin/sudo)
