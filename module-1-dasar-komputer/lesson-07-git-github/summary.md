## Summary

**Yang udah lu pelajari**
- Git nyimpen riwayat perubahan di satu folder. GitHub nyimpen salinan proyek Git secara online.
- Alur harian: ubah file, `git add`, `git commit`.
- `git status`, `git diff`, dan `git log --oneline` buat melihat kondisi dan riwayat.
- `git restore` buat membuang perubahan yang belum di-commit. `git revert` buat membatalkan commit dengan aman.
- Branch buat nyoba perubahan terpisah, lalu `git merge` buat menggabungkan.
- `git remote add`, `git push`, `git clone`, dan `git pull` buat kerja dengan GitHub.
- `.gitignore` buat file yang nggak boleh ikut dilacak.

**Perintah yang paling sering dipakai**

```bash
git status
git add .
git commit -m "pesan yang jelas"
git push
```
