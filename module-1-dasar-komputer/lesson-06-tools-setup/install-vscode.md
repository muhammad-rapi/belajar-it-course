## Install VS Code

**Download**: [code.visualstudio.com](https://code.visualstudio.com/)

**macOS**: Download .dmg, drag ke Applications  
**Windows**: Download .exe, install  
**Linux**: Download .deb/.rpm atau via snap

**Extensions wajib** (install via Extensions tab):
1. **Python** (Microsoft) - Python support
2. **Prettier** - Code formatter
3. **Live Server** - Local web server
4. **GitLens** - Git visualization

**Shortcuts penting**:
- `Cmd+P` / `Ctrl+P` - Quick open file
- `Cmd+Shift+P` - Command palette
- `Cmd+B` - Toggle sidebar
- `Cmd+`` - Toggle terminal

**Settings**:
- Font size: 14-16px
- Auto save: After Delay
- Format on save: ✓

**Test**: Bikin file `test.py`, ketik `print("Hello")`, save. VS Code detect Python.
