## Exercises

**1. Verify installations**
```bash
code --version    # VS Code installed?
git --version     # Git installed?
node --version    # Node.js installed?
npm --version     # npm installed?
```

**2. VS Code setup**
- Install extensions: Python, Prettier
- Change theme (optional)
- Bikin file `hello.py`, run

**3. Git config**
```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --list  # Check config
```

**4. First project**
```bash
mkdir test-project
cd test-project
code .  # Open VS Code
```

Bikin file `index.html`:
```html
<!DOCTYPE html>
<html>
<body>
  <h1>Hello World</h1>
</body>
</html>
```

Open dengan Live Server extension (klik kanan → Open with Live Server).

Done! Lu siap coding. 🎉
