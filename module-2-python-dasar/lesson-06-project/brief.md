## Project Brief

Saatnya apply semua yang udah lu pelajari!

---

### Yang Udah Lu Kuasai

✅ Variables & data types  
✅ String, list, dictionary operations  
✅ If-elif-else conditionals  
✅ For & while loops  
✅ Functions  

---

### Project Options

Pilih **1 dari 3** project, atau bikin sendiri!

**Project 1: File Organizer**
- Organize files by extension (.jpg, .pdf, .txt)
- Move ke folder sesuai tipe
- Automation script

**Project 2: Contact Manager CLI**
- CRUD contacts (Create, Read, Update, Delete)
- Save to JSON file
- Search & filter

**Project 3: Expense Tracker**
- Track income/expense
- Calculate balance
- Export to CSV

---

### Requirements

**Minimal features**:
- Input validation
- Error handling
- Functions (organized code)
- File I/O (save/load data)

**Bonus**:
- Menu loop (user-friendly CLI)
- Search/filter
- Export data

---

### Workflow

1. **Understand** the problem
2. **Plan** functions & data structure
3. **Code** step by step
4. **Test** edge cases
5. **Refactor** (clean up)

---

**Pilih project lu!** Lanjut ke sub-lesson project yang lu pilih.
