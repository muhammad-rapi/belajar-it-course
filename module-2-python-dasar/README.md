# Module 2: Dasar Programming dengan Python

Module ini ngajarin lu **cara ngoding dari nol** pakai Python. Kenapa Python? Karena paling gampang buat pemula, banyak dipake di industry (web, automation, data, AI), dan lu bisa langsung bikin sesuatu yang berguna.

## Apa yang Akan Lu Pelajari

Abis module ini, lu bisa:
- Nulis program Python sederhana
- Paham konsep dasar programming (variables, loops, functions)
- Bikin script automation buat ngirit waktu
- Baca dan debug code orang lain
- Bikin project kecil yang beneran jalan

## Prerequisites

Lu harus udah selesain **Module 1: Dasar Komputer & Internet** dan install Python (di Lesson 6 Module 1 udah dikasih tau caranya).

## Lessons

1. **Hello World & Variables** - Program pertama + cara simpen data
2. **Data Types & Operations** - String, number, list, dictionary
3. **Conditionals (If-Else)** - Komputer bikin keputusan
4. **Loops (For & While)** - Ngulang pekerjaan otomatis
5. **Functions** - Bikin code yang reusable
6. **Project: Automation Script** - Bikin sesuatu yang berguna

**Durasi**: 4-6 minggu (2-3 jam/minggu)

## Cara Belajar Module Ini

- **Jangan skip exercises**. Programming belajarnya dari praktek, bukan cuma baca.
- **Ketik ulang semua code**. Jangan copy-paste. Lu perlu muscle memory.
- **Stuck itu normal**. Semua programmer stuck tiap hari. Pelajarin cara debugging.
- **Bikin catatan sendiri**. Tulis ulang konsep pakai bahasa lu sendiri.
