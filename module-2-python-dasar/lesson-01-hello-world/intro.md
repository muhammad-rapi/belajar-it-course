## Apa itu Programming?

Programming = **ngasih instruksi ke komputer**.

Komputer itu bodoh. Dia cuma bisa ikutin perintah lu **persis kayak yang lu tulis**. Salah ketik satu huruf? Error. Lupa titik koma? Error. Tapi kalau instruksinya bener, dia bisa ngulang pekerjaan ribuan kali tanpa capek.

**Analogi: Ngasih instruksi ke anak kecil**

> Lu suruh anak kecil ambil minum:
> - ❌ "Ambil minum" → dia bingung, minum apa? Di mana?
> - ✅ "Buka kulkas. Ambil botol aqua. Tuang ke gelas. Kasih ke aku." → jelas, step-by-step.

Programming sama persis. Lu harus spesifik.

## Kenapa Python?

Ada ratusan bahasa programming. Kenapa gue ajarin Python?

**Alasan praktis**:
1. **Gampang dibaca** - code Python mirip bahasa Inggris normal
2. **Banyak dipake** - web (Django, Flask), automation, data science, AI
3. **Komunitas gede** - stuck? Google aja, pasti ada yang udah pernah ngalamin
4. **Install simple** - nggak ribet setup kayak Java atau C++

Lu nggak perlu jago Python buat switch ke bahasa lain nanti. Konsep programming itu **universal** (variables, loops, functions). Belajar satu bahasa = belajar cara mikir kayak programmer. Pindah bahasa tinggal belajar syntax doang.
