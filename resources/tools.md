# Developer Tools

Download & setup tools buat coding.

---

## 💻 Code Editor

**VS Code** (Recommended)
- Download: [code.visualstudio.com](https://code.visualstudio.com/)
- Gratis, lightweight, banyak extensions
- Cross-platform (Windows, macOS, Linux)

**Extensions wajib**:
- Python (Microsoft)
- Prettier - Code formatter
- Live Server (buat web development)
- GitLens (Git visualization)

**Alternatives**:
- PyCharm Community (khusus Python, lebih heavy)
- Sublime Text (lightweight, paid)
- Vim/Neovim (advanced, terminal-based)

---

## 🐍 Python

**Python 3.10+**
- Download: [python.org/downloads](https://www.python.org/downloads/)
- Pilih installer sesuai OS
- Windows: Check "Add Python to PATH" waktu install
- macOS: Python udah built-in, tapi update via installer
- Linux: `sudo apt install python3 python3-pip`

**Check installation**:
```bash
python3 --version
pip3 --version
```

---

## 🔧 Git

**Git Version Control**
- Download: [git-scm.com](https://git-scm.com/)
- Windows: Install Git Bash
- macOS: Built-in atau via Xcode CLI tools
- Linux: `sudo apt install git`

**Setup**:
```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

**GitHub account**: [github.com](https://github.com) (gratis)

---

## 🌐 Node.js (untuk web development)

**Node.js LTS**
- Download: [nodejs.org](https://nodejs.org/)
- Pilih LTS version (Long Term Support)
- Include npm (Node Package Manager)

**Check installation**:
```bash
node --version
npm --version
```

---

## 🖥️ Terminal

**Windows**:
- Git Bash (included dengan Git)
- PowerShell (built-in)
- Windows Terminal (modern, [microsoft.com/en-us/p/windows-terminal](https://www.microsoft.com/en-us/p/windows-terminal/9n0dx20hk701))

**macOS**:
- Terminal (built-in)
- iTerm2 (advanced, [iterm2.com](https://iterm2.com/))

**Linux**:
- Terminal emulator favorit lu (Gnome Terminal, Konsole, Alacritty)

---

## 🎨 Browser (untuk web dev)

**Chrome** atau **Firefox** dengan DevTools.
- Chrome DevTools: F12 atau Cmd+Option+I
- Firefox Developer Edition: [mozilla.org/firefox/developer](https://www.mozilla.org/en-US/firefox/developer/)

---

## 📌 Setup Order

1. **VS Code** - code editor
2. **Python** - programming language
3. **Git** - version control
4. **Node.js** - JavaScript runtime (kalau mau web dev)
