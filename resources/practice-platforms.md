# Practice Platforms

Platform buat latihan coding & algorithm.

---

## 🎯 Beginner-Friendly

**Exercism** - [exercism.org/tracks/python](https://exercism.org/tracks/python)
- Gratis
- Mentor review code lu
- Track Python structured
- **Recommend buat pemula**

**Codewars** - [codewars.com](https://www.codewars.com)
- Gamified (rank system)
- Start dari level 8 kyu (easiest)
- Community solutions (belajar dari orang lain)

---

## 💪 Intermediate

**LeetCode** - [leetcode.com](https://leetcode.com)
- Interview prep
- Easy/Medium/Hard problems
- Company-tagged questions (Google, Meta, dll)
- **Paling populer buat job interview**

**HackerRank** - [hackerrank.com](https://www.hackerrank.com)
- Skills certification
- Python, algorithms, data structures
- Company hiring challenges

---

## 🔥 Advanced

**Codeforces** - [codeforces.com](https://codeforces.com)
- Competitive programming
- Weekly contests
- Rating system

**AtCoder** - [atcoder.jp](https://atcoder.jp)
- Japanese CP platform
- Beginner contests tiap minggu

---

## 🌐 Project-Based

**Frontend Mentor** - [frontendmentor.io](https://www.frontendmentor.io)
- Real design → lu code
- HTML/CSS/JS projects
- Community feedback

**Dev Challenges** - [devchallenges.io](https://devchallenges.io)
- Responsive, front-end, full-stack challenges
- Portfolio-ready projects

---

## 📌 Tips

**Pemula**: Mulai dari **Exercism** (structured) atau **Codewars** (fun).  
**Job hunting**: Focus **LeetCode** Easy/Medium (2-3 soal per hari).  
**Build portfolio**: **Frontend Mentor** atau bikin project sendiri.
