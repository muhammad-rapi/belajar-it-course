# Contributing to Belajar IT dari Nol

Terima kasih mau contribute! 🎉

## How to Contribute

### Report Issues
- Typo, broken links, error di code examples
- Confusing explanations
- Missing context

**How**: [Open issue](https://github.com/muhammad-rapi/belajar-it-course/issues/new)

### Suggest Improvements
- Better analogies
- Additional exercises
- New topics to cover

**How**: [Start discussion](https://github.com/muhammad-rapi/belajar-it-course/discussions/new)

### Submit Pull Requests

**Good PRs**:
- Fix typo/grammar
- Improve code examples
- Add exercises with solutions
- Add diagrams/visuals

**Before submitting**:
1. Fork repo
2. Create branch: `git checkout -b fix/typo-lesson-1`
3. Make changes
4. Test (kalau code example, run & verify works)
5. Commit: `git commit -m "Fix typo in lesson 1"`
6. Push: `git push origin fix/typo-lesson-1`
7. Open PR dengan description clear

### Content Guidelines

**Follow existing style**:
- Conversational tone (kamu/aku/kita)
- Indonesian analogies (Gojek, KTP, daily life)
- No AI slop (avoid "Let's dive", "crucial", "landscape", etc)
- Exercises must have hints + detailed solutions

**Anti-AI-slop checklist**:
- [ ] Read aloud - sounds natural?
- [ ] No buzzwords (crucial, pivotal, landscape, testament)
- [ ] No emoji headers
- [ ] Analogies from real life (not abstract)
- [ ] Code examples tested and work

## Code of Conduct

**Be respectful, inclusive, and helpful.**

- Welcome beginners (no "this is easy" gatekeeping)
- No harassment, discrimination, or toxic behavior
- Assume good intent, give constructive feedback

Violations: report via [email/Discord mod] (TBD)
