# Remotion Video Script: CPU, RAM, Storage

**Duration**: 45 seconds  
**Lesson**: Module 1, Lesson 1 - Hardware Concepts  
**Concept**: CPU vs RAM vs Storage (analogi dapur)

## Scene Breakdown

### Scene 1: Setup Dapur (0-10s)

**Visual**:
- Dapur kitchen scene
- 3 areas highlighted:
  1. Kompor (CPU)
  2. Meja kerja (RAM)
  3. Kulkas (Storage)

**Animation**:
- Camera pan across kitchen
- Each area zooms sedikit + label appears

**Text Overlay**:
```
DAPUR = KOMPUTER
```

---

### Scene 2: CPU = Koki (10-20s)

**Visual**:
- Koki icon di kompor
- Hands cooking animation (tumis, aduk)
- Speed indicator (fast)

**Animation**:
- Flames from stove
- Food items being tossed in wok
- Speed lines

**Text Overlay**:
```
CPU = KOKI
Process/masak data dengan cepat
```

---

### Scene 3: RAM = Meja Kerja (20-30s)

**Visual**:
- Counter/table with ingredients
- Items placed on table (nasi, telur, bumbu)
- Small table vs large table comparison

**Animation**:
- Items slide onto table
- Small table = crowded (items fall off)
- Large table = spacious (all fit)

**Text Overlay**:
```
RAM = MEJA KERJA
Simpen bahan yang LAGI DIPAKE
Lebih besar = bisa masak lebih banyak sekaligus
```

---

### Scene 4: Storage = Kulkas (30-45s)

**Visual**:
- Refrigerator door opens
- Many items inside (organized shelves)
- Slow retrieval animation

**Animation**:
- Door opens (slow)
- Hand reaches in, grabs item
- Walks to counter (slow)
- Compare: Counter grab (fast) vs Fridge grab (slow)

**Text Overlay**:
```
STORAGE = KULKAS
Simpen SEMUA bahan (permanen)
Lebih lambat dari RAM, tapi ga ilang
```

---

## Assets Needed

**Illustrations**:
- Kitchen scene (simple 2D)
- Stove/kompor icon
- Counter/table icon
- Refrigerator icon
- Chef/koki character
- Food items (nasi, telur, bumbu icons)

**Colors**:
- Kitchen: warm tones (`#f5e6d3`)
- CPU/stove: red/orange (`#ff6b35`)
- RAM/counter: blue (`#4ecdc4`)
- Storage/fridge: cool blue (`#1a535c`)
